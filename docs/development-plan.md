# 开发计划

本文档是「Planner React 克隆版」的阶段化开发计划，定义里程碑、任务清单与验收标准。领域模型与功能定义见 [`docs/outline.md`](outline.md)。执行时按阶段顺序推进，每阶段完成并验收后再进入下一阶段。

## 里程碑总览

| 阶段 | 名称 | 目标 | 预估规模 | 状态 |
| --- | --- | --- | --- | --- |
| Phase 0 | 工程脚手架 | 可运行、可测试、可 lint 的项目骨架 | 小 | 待开始 |
| Phase 1 | 数据层与状态 | 领域模型、本地持久化、种子数据 | 中 | 待开始 |
| Phase 2 | 看板视图 | Kanban 看板与拖拽 | 大 | 待开始 |
| Phase 3 | 任务详情 | 任务详情面板与全部字段 | 大 | 待开始 |
| Phase 4 | 图表视图 | 统计图表 | 中 | 待开始 |
| Phase 5 | 日程视图 | 日历视图 | 中 | 待开始 |
| Phase 6 | 我的任务与计划中心 | 个人聚合视图 + 计划管理 + 搜索 | 中 | 待开始 |
| Phase 7 | 打磨与发布 | 可访问性、响应式、E2E、部署 | 中 | 待开始 |

---

## Phase 0：工程脚手架

**目标**：建立可运行、可 lint、可测试的 TypeScript + React 工程。

### 任务清单
- [ ] 用 Vite 初始化 React + TypeScript 项目。
- [ ] 配置路径别名、严格 TS、ESLint + Prettier。
- [ ] 引入 Tailwind CSS 并建立基础主题变量（浅色/深色）。
- [ ] 引入 React Router，搭建空壳布局与各视图路由占位。
- [ ] 配置 Vitest + React Testing Library + Playwright。
- [ ] 建立 `src/models`、`src/features`、`src/stores`、`src/repository` 目录骨架。
- [ ] 配置 CI（`pnpm lint` + `pnpm test` + `pnpm build`）。

### 验收标准
- `pnpm dev` 可启动，四个视图路由均可访问（占位页面）。
- `pnpm lint`、`pnpm test`、`pnpm build` 全部通过。
- 提交通过 CI。

---

## Phase 1：数据层与状态

**目标**：建立领域模型、状态管理与本地持久化，注入种子数据。

### 任务清单
- [ ] 用 Zod 定义 Plan/Bucket/Task/Member/Label/ChecklistItem/Comment/Attachment 的 schema 与 TS 类型。
- [ ] 实现 `repository` 接口（本地 `localStorage`/`IndexedDB` 实现，异步接口）。
- [ ] 用 Zustand + Immer 实现 store：计划、存储桶、任务的增删改查。
- [ ] 实现派生/筛选逻辑（按进度、优先级、存储桶、成员、关键词过滤）。
- [ ] 准备种子数据与演示计划。
- [ ] 编写 store 与 repository 的单元测试。

### 验收标准
- 刷新页面后数据可恢复（持久化生效）。
- 所有数据操作走 repository 接口，业务代码不直接触碰存储层。
- 单元测试覆盖核心 reducer/筛选逻辑。

---

## Phase 2：看板视图

**目标**：实现 Kanban 看板，可增删存储桶与任务并拖拽排序。

### 任务清单
- [ ] 实现 `BoardView`、`BucketColumn`、`TaskCard` 组件。
- [ ] 任务卡片展示标题、进度、优先级、截止日期、标签、成员头像、清单完成度。
- [ ] 新建/重命名/删除存储桶。
- [ ] 新建任务；删除任务。
- [ ] 用 @dnd-kit 实现卡片在列内排序与跨列移动。
- [ ] 看板内关键字过滤与字段分组。
- [ ] 组件测试：卡片渲染、增删存储桶/任务、拖拽逻辑。

### 验收标准
- 拖拽跨列后任务所属存储桶正确更新并持久化。
- 卡片信息与 `docs/outline.md` 定义一致。
- 键盘可完成基础操作（可访问性）。

---

## Phase 3：任务详情

**目标**：实现任务详情面板与全部字段编辑。

### 任务清单
- [ ] 实现 `TaskDetailPanel` 及 `ChecklistEditor`、`LabelPicker`、`DatePicker`、`PriorityPicker`、`AssigneePicker`。
- [ ] 编辑标题、备注、进度、优先级、起止日期。
- [ ] 标签管理与分配；成员分配。
- [ ] 清单：添加/勾选/删除/排序。
- [ ] 附件：本地文件引用与列表展示。
- [ ] 评论与活动流。
- [ ] 组件测试与表单校验测试。

### 验收标准
- 详情面板所有字段可编辑、可校验、可持久化。
- 清单完成度实时反映到任务卡片。
- 字段选择器交互符合可访问性要求。

## Phase 4：图表视图

**目标**：实现任务统计图表。

### 任务清单
- [ ] 实现 `ChartsView`。
- [ ] 状态分布图（未开始/进行中/已完成/逾期）。
- [ ] 存储桶分布、优先级分布。
- [ ] 成员工作量分布（每成员任务数）。

## Phase 5：日程视图

**目标**：实现日历视图展示有起止日期的任务。

### 任务清单
- [ ] 实现 `ScheduleView`，支持月/周切换。
- [ ] 按开始-截止日期渲染日历条目。
- [ ] 点击条目跳转任务详情。
- [ ] 组件测试与日期边界测试。

### 验收标准
- 月/周切换正确，跨天任务渲染正确。
- 无截止日期任务不影响日历正常展示。

## Phase 6：我的任务与计划中心

**目标**：实现个人聚合视图、计划管理与搜索。

### 任务清单
- [ ] 实现 `PlanHub`：计划列表、新建/删除/重命名、成员管理。
- [ ] 实现 `MyTasksView`：跨计划聚合分配给当前用户的任务。
- [ ] 「我的任务」按计划/状态/日期过滤与快速完成。
- [ ] 全局搜索（按标题/成员/标签）。
- [ ] 组件测试。

### 验收标准
- 计划中心操作正确且持久化。
- 「我的任务」聚合结果正确、可筛选、可快速完成。

## Phase 7：打磨与发布

**目标**：补齐可访问性、响应式、E2E 测试与部署。

### 任务清单
- [ ] 响应式布局（桌面/平板/移动）。
- [ ] 深色/浅色主题完善。
- [ ] 键盘导航与焦点管理全面自查。
- [ ] 关键流程 Playwright E2E 测试（建计划 → 建桶 → 建任务 → 拖拽 → 完成）。
- [ ] 部署（静态托管）与使用说明更新。

### 验收标准
- 全量测试（单元/组件/E2E）通过。
- 移动端与桌面端均可正常使用。
- 应用可对外访问，README 提供使用说明。

---

## 通用完成定义（Definition of Done）

每个阶段完成需同时满足：

1. 该阶段任务清单全部完成。
2. 对应验收标准全部通过。
3. `pnpm lint`、`pnpm test`、`pnpm build` 通过，且 CI 绿。
4. 若改动领域模型或页面结构，已同步更新 `docs/outline.md`。
5. 新增代码具备相应测试，无未解释的 `any`。
